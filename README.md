# dw_sql_portfolio-project
Building a Data Warehouse with MYSQL Server, including ETL processes, Data Modeling, and Analytics.

#SQL Data Warehouse Project
#Project Overview
This project demonstrates the end-to-end development of a modern SQL Data Warehouse using SQL Server. It follows professional data engineering best practices to consolidate sales data from multiple source systems (CRM and ERP) for advanced analytical reporting.

## Key Features
Modern Data Architecture: Designed a robust, multi-layered architecture consisting of Bronze, Silver, and Gold layers.
ETL Pipeline Development: Implemented automated SQL stored procedures to clean, transform, and load data, ensuring data quality and integrity.
Data Modeling: Built a performant Star Schema model, optimized for business intelligence and reporting.
Documentation & Governance: Includes comprehensive data flow lineage, a data dictionary, and standardized naming conventions.
Best Practices: Followed professional engineering standards including Git version control, technical documentation, and quality validation gates.
#Repository Structure
/data-sets: Contains raw source CSV files.
/scripts: SQL scripts for DDL and ETL stored procedures across all layers.
/documents: Technical documentation including data models and catalog.
/tests: Quality assurance scripts for data validation.
